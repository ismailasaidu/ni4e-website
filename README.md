# NI4E Institutional Website & Digital Membership Platform

A polished React/Vite implementation for the The Nigerian Institution of Energy, Electrical & Electronics Engineers (NI4E).

## Included

- Responsive institutional website
- Homepage hero carousel
- Full NI4E name and institutional positioning
- About, Leadership, Past Presidents, Membership, Chapters, Events, Publications, News and Contact
- Search overlay
- Guided membership registration flow
- Member login and member portal UI
- Administrative dashboard UI
- Interactive event details
- Publication previews
- News article views
- Responsive mobile navigation
- Loading states, toasts, reveal animations and micro-interactions
- Accessibility-friendly focus states and reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Production integration

The interface is structured so the next production layer can connect the approved NI4E backend, authentication, database, document storage and Paystack configuration. Official NI4E content, membership rules, executive records, fees, contact details and credentials should replace the development content before launch.
