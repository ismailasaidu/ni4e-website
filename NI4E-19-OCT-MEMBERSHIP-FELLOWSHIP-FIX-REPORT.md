# NI4E membership and Fellowship correction pass — 19 October 2026

## Membership application changes
- Student programme and current level/year of study are separate required fields; expected completion year is also collected.
- Student applicants selecting `Other` must specify the programme.
- Graduate applicants have completed qualification, institution, graduation year and optional degree classification/result details, plus a career-profile field.
- Associate applicants now provide a stated basis for applying, a description of relevant background, role/experience and contribution evidence.
- Corporate applicants now provide professional registration body/status, area of practice, professional responsibilities/projects and years practising.
- Associate and Corporate upload prompts now name useful supporting evidence rather than a vague “attach evidence if available” message. At least one supporting file is required when no category-specific documents have been configured.
- Membership category cards and the selected category panel have a more anchored border, depth, spacing and responsive layout. The page displays only officially configured fees.

## Fellowship changes
- Fellowship by Education now has separate research-project, scholarly-output, funding/collaboration, supervision, academic-service and innovation/impact fields rather than reusing the Direct Fellowship NI4E-AGM/branch questions.
- Route-specific validation checks Education evidence separately from Direct Fellowship professional and institutional contributions.
- Application navigation now targets the actual form box and forces the reveal section visible; if an existing application means the form is unavailable, navigation targets the existing-application status instead of an empty section.

## Validation and limitations
- TypeScript parser checked 43 JS/JSX/TS/TSX source files: zero parse diagnostics.
- Production build and live browser/Supabase/auth/storage tests have not been completed in this environment. Test these with the configured project before deploying.
- Associate and Corporate eligibility thresholds and mandatory document lists remain subject to official NI4E policy; this pass asks for relevant information without inventing official eligibility rules or fees.
